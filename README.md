# 🎮 3D Dodging Game

**3D Dodging Game** is a simple 3D game developed in Unity where the player must move through the level while avoiding obstacles.

The project was created to practice fundamental Unity 3D development concepts such as player movement, physics, collisions, obstacle interaction, and basic C# scripting.

## 🎯 Objective

The goal of the game is to navigate the player through the level while avoiding obstacles.

Players must control their movement carefully and dodge objects in their path to reach the end of the course.

## ✨ Features

* 🎮 3D player movement
* 🧱 Obstacle-based gameplay
* 💥 Collision detection
* 🕹️ Keyboard controls
* 🏁 Level progression
* 🎥 Third-person / 3D camera setup
* ⚙️ Unity physics
* 💻 Gameplay logic written in C#

## 🛠️ Built With

* **Unity 6**
* **Unity Version:** `6000.3.10f1`
* **C#**
* **Unity 3D**
* **Unity Physics System**

## 🎮 Controls

| Action        | Control   |
| ------------- | --------- |
| Move Left     | `A` / `←` |
| Move Right    | `D` / `→` |



This project is intended for learning purpose.
